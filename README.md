# Researches

1. Acoustic Signatures of Parkinson’s Disease:Leveraging Voice Data for Predictive Insights

This study presents a machine learning framework for noninvasive Parkinson’s disease detection using 195 voice recordings. By evaluating 12 classification models, the researchers developed a soft voting ensemble combining the top three classifiers. This ensemble achieved peak performance on an unseen test set, delivering 98.88% accuracy and 98.90% precision and recall. Ultimately, the framework offers a highly reliable, cost-effective, and interpretable alternative to traditional, subjective screening methods.

2. Cross-Domain Knowledge Mapping  Biomedical VS AI Research

This project uses text mining, TF-IDF feature extraction, UMAP dimensionality reduction, and K-means clustering in R to analyze a cross-domain corpus of biomedical and AI research abstracts. It successfully maps domain-specific vocabularies and surfaces overlapping knowledge transfer zones where AI methodologies intersect with healthcare challenges.
